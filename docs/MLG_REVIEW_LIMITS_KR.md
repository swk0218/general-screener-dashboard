# 사업 역할 검토의 제한 상태

이 기능은 기본 비활성 상태의 보조 검토 화면입니다. 문서에서 확인한 사업 역할과 기존 규칙 표시의 대조를 구분하며, MLG 전체 재생이나 정확도 개선을 검증했다는 의미를 부여하지 않습니다. 역할 분류로 기존 점수·순위·경보를 바꾸지 않습니다.

- MLG 자료 시점/계약을 확인하지 못하거나 기준 세션이 다르면 문서 근거는 볼 수 있지만 기존 분류와의 대조와 차이 필터는 보류합니다.
- 생성/검증이 완료되지 않은 결과는 이전 role 값이 남아 있어도 표시하지 않습니다.
- 미확인 역할에 ‘기존 분류와 일치’ 배지를 붙이지 않습니다. 자료 없음은 사업 부재가 아닙니다.
- 전체 원입력이 없는 상황의 부분 검사가 엔진 전체 검증을 대신하지 않는다는 설명을 상세 영역에 제공합니다.
- 사용자가 즉시 확인할 수 있도록 ‘대조 보류’, 자료 기준일, 원문 근거와 제한을 색상 외 텍스트로 표시합니다.

`mlg_input_hold.json`은 backend validator로 확인한 공개 개발 fixture이며 실제 엔진 결과나 현재 투자 판단이 아닙니다. 이 fixture와 실패 상태를 320/390/1440 폭의 브라우저 검사에 포함했습니다. 유효 문서 자료와 엔진 재생 가능 여부를 동일하게 취급하지 않습니다. 실제 분류 품질·전체 MLG 재생은 별도 출시 조건입니다.

개발 CI는 기존 Playwright1.58.2를 유지하고 지원되는 Ubuntu24.04에 고정하며 job을8분으로 제한합니다. 운영 Pages workflow와 의존성 lockfile은 변경하지 않습니다. OS 지원 경계 재현과 실제 CI 성공은 다른 증거입니다.
