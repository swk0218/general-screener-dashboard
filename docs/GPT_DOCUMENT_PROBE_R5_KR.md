# 합성 동일명제 모순 검증 r5

실제 GPT 응답이나 최종 서비스 데모가 아닌 오프라인 계약 검증입니다. backend의 별도 document probe는 실제 요청 구성/주입 응답 파싱/검증을 거쳐 기존 암호화 sealer를 사용하고, 이 앱의 provider_test reader가 이를 소비합니다. `TEST` 출처는 `example.invalid`를 쓰며 실제 SEC/FMP 자료로 표시하지 않습니다. 화면에서는 외부 링크 대신 합성 검증 자료라는 설명을 제공합니다.

TEST 자료는 demo=true/provider_test/synthetic_probe에서만 읽습니다. 일반 provider 및 fake artifact로 바꾸거나 일반 reader로 열면 거부합니다. 기존 public 복사 제외·배포물 scan·기본 OFF 자산 해시 검증을 유지합니다. 비공개 preview 디렉터리의 실제 암호문으로 모바일/데스크톱 화면에서 양쪽 문장 보존과 유보 표시를 확인합니다.

자료 공시일, 문서 현재형, 실제 관측 available_at, 생성일을 구분합니다. 2025 공시가 있다고 2026 관측 자료를 2025 당시 수집 자료로 간주하지 않습니다. 일반 경쟁 위험을 공급 역할 반증으로 강제하지 않습니다. 합성 모순 테스트를 실제 공시 충돌 처리 품질이나 투자 성과로 보고하지 않습니다.

이번 검증은 운영 Radar 암호문 복호화·게시 연결, TENX/MLG archive 기준일 결측, 실제 GPT 근거 추출 품질의 미검증 상태를 해소한 것으로 표시하지 않습니다. 운영 배포와 유료 시험은 보류입니다.
